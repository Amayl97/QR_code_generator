# QR Code Generator

A simple Python project that generates a QR code from a URL using the `qrcode` library. The generated QR code is saved as an image and can be scanned to open the linked website.

## Features
- Generates QR codes from URLs.
- Customizable QR code size and border.
- Customizable foreground and background colors.
- Saves the generated QR code as an image.

## Tech Stack
- Python
- `qrcode`
- Pillow (image processing)

## How to Run

1. Install the dependency:
   ```bash
   pip install qrcode[pil]
   ```
2. Run the Python script:
   ```bash
   python main.py
   ```
3. The QR code image will be generated and saved locally.
